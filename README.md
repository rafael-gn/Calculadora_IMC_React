📌 Sobre o projeto

Projeto Front-End desenvolvido em React para cálculo do Índice de Massa Corporal (IMC), oferecendo uma interface interativa e responsiva para entrada e validação de dados. A aplicação realiza cálculos em tempo real e apresenta classificações corporais de forma dinâmica, aplicando conceitos de componentização, gerenciamento de estado e manipulação de formulários no React.

🚀 Tecnologias utilizadas

React.js

JavaScript

CSS3

HTML5

⚙️ Funcionalidades

Cálculo automático de IMC

Validação de dados inseridos

Exibição de classificação corporal

Interface intuitiva e responsiva

Atualização dinâmica dos resultados
